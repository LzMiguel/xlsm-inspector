# To-DOs

TO-DOs de melhorias mapeados de forma manual

## interface

- [ ] Opção padrão é exportar tudo no arquivo compilado para IA.
- [ ] Se desmarcado a opção de exportar tudo, então exibir as demais opções.
      A opção de exportar para json fica separada e sendo considerada uma opção a parte, que não depende da opção de exportar tudo.
- [ ] Adicionar sessoes gerais de conteudo na sidebar, como "VBA", "Power Query", "Planilhas" e "Células".
      A intenção aqui é que o usuário possa selecionar rapidamente o que deseja exibir, e manter as abas no arquivo.
      Deixando de existir aquele menu dinamico de seleção de abas, que é confuso e não é intuitivo.
- [ ] Adicionar opção de exportar apenas o conteúdo da aba ativa.
- [ ] Ocultar tudo de VBA que não tenha codigo, como planilhas vazias, módulos vazios, etc.
      Por vezes tem modulos apenas criados e planilhas apenas com "Option Explicit", que não tem utilidade para o usuário.
- [ ] Os nome das exportações ja vem por padrão com o nome do arquivo e o que foi exportado, com o usuario podendo alterar apenas na janela do windows.
- [ ] Transferir a opção de selecionar o que vai exportar para um outro menu na interface de exportação, que seja mais intuitivo e fácil de usar.
- [ ] Adicionar compactação dos cards iniciais na rolagem do conteudo, para que o usuário possa ver mais conteúdo sem precisar rolar tanto a tela.
- [ ] Adicionar opção de line breaks nas previews de código, para que o usuário possa ver o código de forma mais organizada e legível.
- [ ] Adicionar "memoria" de estado para a interface, para que o usuário não precise ficar reconfigurando a interface toda vez que abrir o programa.
- [ ] Adicionar opção de colapsar itens de diagnosticos
